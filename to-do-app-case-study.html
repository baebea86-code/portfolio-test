## Project: To-Do App ### Overview This project is a simple to-do list application that allows users to add and manage tasks. I built it to practice JavaScript fundamentals and DOM manipulation. ### Problem I wanted to understand how to make a webpage interactive instead of static, especially how user input can change what’s displayed on the screen. ### Solution I used JavaScript to capture user input, create new elements, and update the task list dynamically. This helped me understand how HTML, CSS, and JavaScript work together. ### Challenges One challenge was handling user input correctly and making sure tasks were added without breaking the layout. I also struggled with selecting and updating elements in the DOM. ### What I Learned * How to use `querySelector` and `addEventListener` * How to update the DOM dynamically * The importance of structuring code clearly ### Future Improvements In the future, I would add features like saving tasks, editing items, and improving the design.
