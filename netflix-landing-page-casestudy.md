🎬 Netflix Clone Landing Page – Case Study

I built a Netflix-inspired landing page using only HTML and CSS to practice creating structured and visually appealing layouts. The goal was to replicate the look and feel of Netflix while ensuring the design is responsive across different screen sizes.

I used Flexbox and Grid to organize sections like the navbar, hero, and feature areas. A key challenge was making the layout responsive without JavaScript, which I solved using media queries and flexible units.

This project helped me improve my CSS layout skills and better understand responsive design.
